# Описание

IdleAnimation — это плагин для RPG Maker MZ, который добавляет персонажам лёгкую «оживлённую» анимацию, когда они стоят на месте. Вместо статичного спрайта персонаж начинает слегка смещаться по заданной последовательности шагов, создавая эффект дыхания, покачивания или небольшого движения.

Плагин работает как с игроком, так и с NPC. Для NPC можно задавать несколько различных конфигураций анимации и применять их через теги в заметках события. Благодаря этому разные персонажи могут иметь разные типы idle-анимации — например, лёгкое покачивание, диагональные движения или сложные комбинированные циклы.

Анимация полностью управляется параметрами плагина и последовательностью шагов, что позволяет гибко настраивать поведение без изменения кода. Поддерживаются движения по осям X и Y, диагональные смещения, регулировка скорости и амплитуды, а также опциональный режим реверса, который возвращает персонажа в исходную точку плавным обратным проходом.

Плагин не вмешивается в стандартную систему движения RPG Maker и работает только тогда, когда персонаж стоит на месте, поэтому он не конфликтует с обычными анимациями ходьбы или другими механиками.

# Как работает плагин

Плагин создаёт анимацию покоя (Idle animation / анимация простоя), смещая спрайт персонажа относительно его стандартной позиции на небольшие значения по осям X и Y.

Анимация формируется из последовательности шагов Sequence (последовательность). Каждый шаг представляет собой смещение по горизонтали X или вертикали Y. Шаги записываются через запятую и выполняются по порядку, образуя циклическую анимацию.

Примеры шагов:

```
x - Спрайт смещается вправо
-x - Спрайт смещается влево
y - Спрайт смещается вниз
-y - Спрайт смещается вверх
x+y - Спрайт смещается по диагонали вниз-вправо. Одновременно применяется: +X (вправо); +Y (вниз)
-x-y - Спрайт смещается по диагонали вверх-влево. Одновременно применяется: -X (влево); +Y (вниз)

```
Направления на экране RPG Maker:
                           
```

            -y                       
             ↑                       
-x-y  ↖             ↗  x-y          
                                    
 -x ←        •        → x            
                                     
-x+y  ↙            ↘  x+y           
             ↓
             y
 
```

Параметры AmplitudeX (амплитуда X) и AmplitudeY (амплитуда Y) задают силу смещения спрайта в пикселях. Эти значения определяют, насколько сильно персонаж будет отклоняться от своей исходной позиции.

Параметр Speed (скорость шага) определяет, сколько кадров требуется для выполнения одного шага последовательности. Чем больше значение, тем медленнее происходит движение.

Если включён параметр EnableReverse (включить реверс), после завершения всей последовательности анимация выполняется в обратном порядке. Это создаёт более плавное возвращение персонажа в исходную точку и делает движение визуально естественнее.

Анимация запускается автоматически, когда персонаж находится в состоянии Idle (покой), то есть стоит на месте. Во время движения или выполнения других действий эффект отключается.

# Как установить плагин

Плагин устанавливается в проект RPG Maker MZ стандартным способом.

Установка:

  1) Скачайте файл idle_animation.js из репозитория GitHub.

  2) Перейдите в папку проекта RPG Maker MZ:

     ```
     your_project/js/plugins/
     ```

  3) Поместите файл idle_animation.js в эту папку.

  4) Откройте Plugin Manager в RPG Maker MZ и добавьте плагин idle_animation в список плагинов проекта

# Настройка плагина

После установки плагина в Plugin Manager (менеджере плагинов) RPG Maker MZ появятся основные параметры.

- Sequence (последовательность)
  Определяет порядок смещений спрайта. Шаги записываются через запятую и могут включать движения по осям X и Y.
  
  Пример:
  
  ```
  x,x+-y,-x+y,-x,-x,-x+-y,x+y,x
  ```

- AmplitudeX (амплитуда X)
  Определяет смещение спрайта по горизонтали в пикселях.

- AmplitudeY (амплитуда Y)
  Определяет смещение спрайта по вертикали.

- Speed (скорость шага)
  Количество кадров, за которое выполняется один шаг последовательности.

- EnableReverse (включить реверс)
  Если параметр включён, последовательность шагов после завершения будет проигрываться в обратном порядке.

- EnablePlayer (включить для игрока)
  Позволяет включить или отключить анимацию для игрока. Анимация игрока работает только тогда, когда персонаж стоит на месте.

## Использование для NPC

Чтобы применить анимацию к NPC, необходимо добавить тег в заметки события (Event Note / заметки события):

```
<IdleAnimation>
```

NPC с этим тегом будут использовать основные параметры плагина как и игрок.

## Индивидуальные настройки NPC

Плагин поддерживает несколько отдельных конфигураций анимации:

```
IdleAnimation 1
IdleAnimation 2
IdleAnimation 3
...
```

Каждая конфигурация содержит собственные параметры:

- Sequence (последовательность)

- AmplitudeX (амплитуда X)

- AmplitudeY (амплитуда Y)

- Speed (скорость шага)

- EnableReverse (включить реверс)

Чтобы применить конкретную конфигурацию к NPC, используйте соответствующий тег:

```
<IdleAnimation n> где n - номер конфигурации
```

## Добавление новых конфигураций

При необходимости можно добавить дополнительные конфигурации/параметры, если 1 сновной и 10 вспомогательных конфигураций вам не хватило.

Для этого:

1) Откройте JS-файл плагина.
2) Скопируйте блок параметра, например:
```
@param IdleAnimation 10
@text Настройки для NPC 10
@type struct<IdleAnimationConfig>
@default {"Sequence":"","AmplitudeX":"1","AmplitudeY":"1","Speed":"8","EnableReverse":"false"}
@desc Персональные настройки для NPC с тегом <IdleAnimation 10>.
```
3) Вставьте скопированный блок по аналогии с другими.
4) Изменить число 10 в строках @param, @text, @desc на нужное вам. В нашем случае 11.
5) После этого в заметках события используйте тег <IdleAnimation ВАШ НОМЕР>, в нашем случае <IdleAnimation 11>. Код плагина автоматически подхватит любой параметр с именем "IdleAnimation N", где N — число.
