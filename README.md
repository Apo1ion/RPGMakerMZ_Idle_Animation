# RPGMakerMZ_Idle_Animation
IdleAnimation — это плагин для RPG Maker MZ, который добавляет персонажам лёгкую «оживлённую» анимацию, когда они стоят на месте. Вместо статичного спрайта персонаж начинает слегка смещаться по заданной последовательности шагов, создавая эффект дыхания, покачивания или небольшого движения.
